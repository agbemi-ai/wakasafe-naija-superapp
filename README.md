# WakaSafe: Your Family's Well-being

Build WakaSafe AI - A Safety, Health & Family Super App for Nigeria

BRAND & DESIGN:

- App name: WakaSafe AI

- Theme: Green #10B981 and White #FFFFFF, clean modern UI

- Mobile first. Bottom navigation bar. Poppins font.

- Nigeria context: use ₦ Naira, Lagos/Abuja time WAT UTC+1

CORE FEATURES - BUILD ALL 16 TABS:

1. **Home Dashboard**: Quick actions, Safety score, Emergency SOS button, Weather

2. **Health Tracker**: Log symptoms, BP, Sugar, Weight. View charts. Export PDF

3. **Baby Care**: Growth tracker with useCreateGrowthLog hook. Vaccination schedule, Milestones, Feed/Sleep log

4. **Family Locator**: Live location sharing for family members. "I'm Safe" check-in

5. **SOS Emergency**: 1-tap call 112, 199. Send location to 3 contacts. Fake call button

6. **Hospital Finder**: Map of nearby hospitals, clinics, pharmacies in Nigeria. Filter by 24/7

7. **AI Health Chat**: Ask health questions. Disclaimer: "Not medical advice"

8. **Drug Info**: Search drugs, dosage, side effects. Nigerian drug database

9. **First Aid Guide**: Step by step guides with images. Offline access

10. **Period & Fertility Tracker**: Cycle log, predictions, reminders

11. **Mental Wellness**: Mood tracker, breathing exercises, emergency helpline

12. **Insurance**: Store NHIS and private insurance details. Claim checklist

13. **Wallet**: Track medical expenses in ₦. Budget for health

14. **Community**: Anonymous forum for health questions

15. **Profile**: User details, emergency contacts, blood group, allergies

16. **Settings**: Notifications, Language, Privacy, Data export

PAYWALL & MONETIZATION:

TECH REQUIREMENTS:

- React + TypeScript + Tailwind CSS

- Use localStorage for data storage for now

- Responsive design for mobile

- Create all hooks needed including useCreateGrowthLog

- No runtime errors. All routes must work

- Add loading states and error handling
